# Changelog

## 0.1.3 — 2026-09-09

- Панель и локальный валидатор переведены на NikaS UI Standard 2.2 и
  Navigation Contract 1.2; канонические документы синхронизированы.
- Оболочка привязана к фактическому `ha-panel`, Header и Bottom Tab Bar получили
  канонические строки 60/64 px, а иконки нижнего меню уменьшены до 26 px.
- Добавлен capture-phase boundary guard против pull-to-refresh и внешней
  прокрутки Home Assistant на краях рабочей области.
- Кнопка «Обновить» больше не перезагружает браузер: она вызывает read-only
  `nikas_house.refresh`, блокирует дубли, выдерживает минимум 900 мс и показывает
  результат 1400 мс.
- При отсутствующем или повреждённом приватном inventory маршрут House остаётся
  зарегистрированным с явным состоянием «Нет данных» вместо ложной нормы.
- Интерфейс обновлён до UI v1.0.2; интеграция — до 0.1.3. Политика публикации
  House через `main`, без GitHub Releases, сохранена.

## 0.1.2 — 2026-09-08

- Карточка «Вода» на панели House теперь открывает автономный маршрут
  `/dashboard-water`, принадлежащий `ha-water-accounting`.
- Маршрут Water добавлен в безопасный межпанельный hand-off без переноса кода
  панели в House.
- Интерфейс обновлён до UI v1.0.1; идентификаторы кэша изменённых frontend-
  модулей обновлены.

## 0.1.1

- Повторно опубликована утверждённая локальная иконка `NikaS House` через
  версионированное обновление HACS.
- Домены, маршруты, сущности и интерфейс UI v1.0.0 не изменены.

## 0.1.0

- Выделена панель «Дом» из `ha-contract-generated-ui` `0.38.2` на коммите
  `f5bff8145eef20475cf3e3f9f470e94d564b72fc` без изменения утверждённой
  визуальной композиции и логики состояний.
- Добавлена автономная интеграция `nikas_house` и параллельный маршрут
  `/dashboard-house-v13/home` с интерфейсом `UI v1.0.0`.
- Изолированы статические пути, frontend cache keys, web components, ключ
  bootstrap-навигации и локальное состояние масштаба от версии v12.
- Сохранены фиксированные Header и нижнее меню, точечное обновление телеметрии,
  pinch-to-zoom и сброс масштаба двойным касанием двумя пальцами.
- Маршруты LIDER, Keenetic, ZONT, Access и Rooms сверены по репозиториям их
  владельцев; ворота и точки доступа направлены в `/dashboard-access-v1/home`.
- Добавлен одноразовый безопасный перенос только проверенных House-привязок в
  собственный приватный runtime-каталог без изменения исходного инвентаря.
- Добавлены HACS, Hassfest, Python, JavaScript, deterministic-build и
  cold-registration проверки. Публикация выполняется через `main`, без Releases.
