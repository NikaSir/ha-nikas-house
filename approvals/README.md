# Render approvals

Reviewed `RenderApproval v1` documents may be stored here when a semantic dashboard change is intentionally accepted for release.

Do not commit placeholder approvals. An approval must contain the exact baseline dashboard SHA-256, candidate dashboard SHA-256 and semantic-diff SHA-256 produced by the candidate under review, together with a reviewer identifier and rationale.

Any candidate or diff change makes the old approval invalid by design.
